# 2026-06-11 Session — conus HRRR ingest fixed end-to-end (mirror + resilience + regrid cache)

Started from "where are we / what's next for commercial." Assessment: post-race
loop is done; the biggest *existing-feature* blocker was the failing conus HRRR
ingest (1200 s timeouts + NOAA `.idx` crashes → `wind_snapshot`/`performance`
null, pre-race auto-route gated). Fixed it in three layers, verified in prod.

## Root causes (all three were real)

1. **NOMADS throttling** — all 19 HRRR files downloaded sequentially from
   `nomads.ncep.noaa.gov`, which rate-limits aggressively. Stalled responses
   blew the 20 m Cloud Run task timeout; transient `.idx` connection failures
   survived only 3 retries then crashed the job (`weather_ingest.py:148`).
2. **Brittle pipeline** — any non-404 error on ONE fhour aborted the whole
   cycle run; earlier fhours were in Redis but no manifest was written, so the
   cycle was unusable. One bad file out of 19 = whole cycle lost.
3. **CPU-bound regrid** — `scipy.griddata` rebuilt a Delaunay triangulation of
   ~1.9M HRRR points on EVERY call (2× per fhour + nearest-fill passes), for
   geometry that never changes. ~60 s/fhour → 19 m 12 s total, 48 s under the
   timeout on a good day, over it on a bad one.

Latent bug also fixed: `latest_cycle()` was recomputed per fhour, so a slow
run crossing an hour boundary could mix two cycles into one manifest.

## Fixes

1. **Mirror-first downloads** — NOAA NODD S3 buckets
   (`noaa-hrrr-bdp-pds` / `noaa-gfs-bdp-pds.s3.amazonaws.com`; same layout,
   same `.idx`, no throttling) primary; NOMADS kept as ordered fallback per
   fhour. 404 also falls through (mirror can lag publication by minutes);
   all-hosts-404 still surfaces as 404 so the "not yet published" stop works.
2. **Skip-and-continue** — `CyclicalIngestPipeline.run_cycle` now skips a
   fhour on any non-404 failure and finalises the manifest with what landed;
   raises only if ZERO fhours land. The forecast loader interpolates across
   manifest gaps (verified: `_pick_bracketing` makes no contiguity assumption).
   Manifest `reference_time` now derives from `cycle_iso`, not
   `valid_times[0]` (F00 may be the skipped one). Benefits currents ingest
   automatically via the shared pipeline.
3. **Cached regridder** — Delaunay triangulation, simplex location,
   barycentric weights, and nearest-fill indices precomputed once per
   (grid fingerprint, bbox, resolution) and cached at module level in
   `grib.py`; per-fhour regrid is a numpy gather + weighted sum. Numerically
   identical to `griddata` (same triangulation/interpolation) → **no
   ENGINE_VERSION bump**. Only small index/weight arrays retained (~few MB).
4. **Pinned cycle** — `(date, cycle)` resolved once per worker run.

## Decisions + rationale

- **Mirror-first over NOMADS-only retry tuning** — NOAA directs high-volume
  consumers to NODD; removes the throttling class entirely; NOMADS stays as
  fallback so a mirror outage degrades, not breaks.
- **Skip-and-continue over loud failure** — pinned contract reversed
  deliberately: a partial cycle beats a null `wind_snapshot`; all-fail still
  exits non-zero for Scheduler retry.
- **Weights cache over pyproj/LCC bilinear** — identical numerics, no new
  dependency, no output drift, no ENGINE_VERSION implications. Rejected
  `--cpu=2` (Qhull/eccodes single-threaded).

## Technical debt flagged

- Skip-and-continue means a job can exit 0 with gaps in a cycle; gap count is
  logged (`skipped fhour(s)`) but nothing alerts on it — folds into the job
  alerting item.
- `_grid_fingerprint` trusts shape + 6 sampled coords to identify the HRRR
  grid; a hypothetical same-shape/same-corners grid change would silently
  reuse stale weights. Acceptable (HRRR grid is fixed by NOAA spec).
- Cowork sandbox note: the E:\ repo mount served stale content mid-session;
  verification was staged via the outputs mount instead. Windows remains the
  source of truth for test runs.
