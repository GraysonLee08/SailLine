# Session summary — 2026-07-07 (continues 2026-07-05/06)

## What we worked on

Field-testing and debugging the persistent-recording + watchdog stack from 07-05/06, which surfaced and fixed **three latent bugs in the native uploader that had never been validated** (the flag shipped OFF since Phase 4), plus assorted UX/infra fixes. Four dog-walk test sessions across two days drove the diagnosis.

## The three native-uploader bugs (in discovery order)

1. **`locationTemplate` in the wrong config group.** v5 moved it into `persistence:` — our code passed it top-level with a comment claiming the opposite. Silently ignored (Metro doesn't type-check; Windows `tsc --noEmit` would have flagged it). Fixed in `backgroundGeolocation.ts`.
2. **Token refresh wiped `http.url`.** `setAuthHeader` sent a *partial* http block (`{http: {headers}}`); the native TSConfig treats the group as a unit, so the rotation — which fires seconds after start via onIdTokenChanged — erased the url. Result: 543 captured / 0 uploaded (07-07 Test Walk debrief). Fixed: module-level `lastNativeHttpConfig`, `setAuthHeader` re-sends the complete block.
3. **Stationary-state capture starvation (the 81-min disease, again).** Sessions sat in Transistorsoft's STATIONARY state: JS got full-rate *sample* locations (UI looked fine), the plugin persisted only 1 heartbeat fix/min (the :30-past-the-minute POST signature). Fixed with a forced-moving watchdog: `onMotionChange(isMoving=false)` while recording → immediate `changePace(true)` + ring-buffer log; `stopTimeout: 30` as backstop; `onHeartbeat` logged as a tell.

**Validated 07-07 19:00 test:** ~8.8 KB GPS batches (≈85–100 pts) throughout, ~800–900 of 1,193 captured points landed; queue peaked 367 and drained to 0.

Also fixed on the wire: template optionals (`sog_kts`/`cog_deg`/`gps_acc_m`) are now **quoted** — v5 emits `undefined` (not v4's `-1`), and an unquoted missing value rendered invalid JSON that 422'd whole batches. Backend `telemetry.py` validator extended: `""`/`"NaN"`/junk strings → null, numeric strings parsed; strict fields (t/lat/lon) unchanged. Tests added in `test_telemetry.py`.
