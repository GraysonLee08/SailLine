   `ALTER TABLE user_profiles ADD COLUMN IF NOT EXISTS app_settings
   JSONB NOT NULL DEFAULT '{}'::jsonb` run directly in Studio

   — in the return checklist, confirm it ran.
   Everything else in the chain was verified healthy: tier=pro,
   ANTHROPIC key (AI summary generated fine), SSE + TacticianCard
   delivery path, sog_ms conversion deployed (push 07-09 21:46).

2. **"Next mark is the Start / a mark we already passed" — client
   bug, not server.** `useNextMarkGuidance` (mobile) fed only the
   last 120 points (~2 min) into a FRESH `MarkRoundingDetector` on
   every fix (2026-06-30 perf throttle). Once a rounding scrolled out
   of the window the replay found no passes and the card regressed to
   mark 0. It also used `radiiForCourse()` = 400/450 m distance radii
   regardless of race mode, and never read the server's `mark_passes`

   server's live detection was fine (telemetry continuous; gate

3. **False Mark 1 pass — CPA cross-talk.** Marks 1 and 2 are 67 m

## Files changed

- `backend/app/services/tactics/pipeline.py` — opt-out `app_settings`
  read wrapped in try/except → any failure reads as "not opted out"
  and the evaluation proceeds (this bug class ate two races; an
  opt-out check must never cost a call). Safe: no explicit
  transaction on that connection, so a failed statement doesn't

## Decisions + rationale

- Next-mark index is server-authoritative, same trust model as
  auto-stop trusting server `ended_at`. Local replay kept only as a
  pre-first-fetch fallback (wrong-but-present beats blank at mount;
  server takes over ≤ 15 s).
- Clamp factor 0.45 (two adjacent clamped radii can't overlap),
  floor 25 m (below that GPS noise starts missing genuine tight
  roundings — a worse failure than cross-talk).
- Gate geometry (1852 m start/finish lines, 1000 m rounding rays)
  deliberately NOT clamped tonight — generous lines are a design
  decision for real RC lines. Flagged as debt (below).
- Opt-out guard logs WARNING and continues, rather than tracing a new
  exit reason — keeps the pinned exit-reason set stable.
