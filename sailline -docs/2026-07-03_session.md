# Session summary — 2026-07-03

## What we worked on

Post-race AI analysis upgrade (full spec: derived metrics + prompt v4 + pre-race
brief). Replaced the v3 recap+tips coach note with a quantitative analysis
pipeline: deterministic Python computes every metric (start, legs, maneuvers,
shifts, laylines, roundings, leeway/current, wind timeline, tactician-call
compliance), and a Sonnet-class model synthesizes four sections — summary,
what worked, what cost us (ranked, EXECUTION/DECISION tagged, seconds), and a
same-conditions playbook. Playbooks carry a machine-readable condition
signature, and the live tactician now matches today's forecast against past
playbooks and injects matched directives into the advisor prompt (pre-race
brief).

## Decisions and rationale

1. **Structured JSON output, not markdown sections** — renders natively in
   web/mobile and makes the playbook machine-readable for the pre-race
   matcher. Content follows the spec's four sections exactly.
2. **Replace `ai_summary` in place, PROMPT_VERSION 3 → 4** — no migration, no
   dual columns. UIs tolerate the old shape until regen.
3. **Full derived payload persisted on the row** (`ai_summary.analysis`) —
   review UI can render start/leg/maneuver numbers without recompute; matcher
   reads `playbook.signature` directly. ~15–25 KB per race, acceptable.
4. **Signature is deterministic Python** — the model never invents it.
5. **`--all` requires `--regen-analysis` to regenerate stale versions** — a
   routine backfill must not burn one Sonnet call per historical race.
6. **Heel summary rides inside the payload** — preserves v3's heel-discipline
   coaching without a spec change.
7. **Favored-end convention: ends labeled A/B relative to line bearing** — a
   single stored start mark cannot identify the physical pin; the prompt is
   told so the model never claims to know. Spec's own "verify sign against a
   known race" caveat still open.
8. **Learned detector thresholds + compliance auto-tuning deferred** — brief
   injection only this pass; signature schema designed so tuning layers on
   later without rework.
