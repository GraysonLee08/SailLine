## The five-layer bug chain (all fixed + verified)

1. **`race-postprocess` exit(2)** — `job_trigger.py` sent
   `["--race-id", <uuid>]`. Cloud Run **replaces** (not merges)
   `containerOverrides.args`, dropping the baked `-m workers.race_postprocess`,
   so the container ran `python --race-id <uuid>` → interpreter exit 2.
   Fix: send the full arg list.
2. **`mark_passes` off-by-one** — two writers (manual-pass endpoint vs auto
   detector) used incompatible "next index" logic on one JSONB array.
   Decision: **remove manual mark-passing entirely** → single writer →
   the bug class is impossible. Missed-mark notification kept informational.
3. **JSONB double-encoding** — writers did `json.dumps(x)` into a `::jsonb`
   param while the global asyncpg codec (`db.py`) also json-encodes →
   columns stored as a JSON *string* of an array. Crashed `compute_stats`
   (worker exit 1) and the `/stats` endpoint (500 on legacy rows). Fix:
   writers pass plain objects (root cause); readers coerce defensively for
   legacy rows.
4. **Circular import** — `weather → routing → weather` crashed the worker
   at module load. Masked for weeks because the job ran a stale May-15
   image; surfaced once CI repointed the job to current code. Fix: lazy
   `from app.services.weather import load_forecast_for_race` inside
   `compute_route` (the only weather→routing back-edge).
5. **Anthropic client / httpx** — `httpx 0.28` removed the `proxies` kwarg
   that `anthropic 0.39` passes → AI client failed to build → recaps empty.
   Fix: pin `httpx==0.27.2`.
   Plus **Cloud SQL connector "different loop"** crash under the worker's
   short-lived `asyncio.run()` → `Connector(refresh_strategy="lazy")`.

## Decisions + rationale
- **Remove manual mark-passing** instead of fixing the dual-writer indexing —
  a racer doesn't touch the phone; single writer is simpler and kills the bug
  class. `source` field dropped (test data only, no migration).
- **JSONB: fix writers + keep read shims** — root-cause the writers, but
  tolerate legacy double-encoded rows on read rather than run a backfill
  migration (it's all test data; readers already shimmed).
- **httpx pin over anthropic bump** — keeps the anthropic API the code uses
  unchanged; smallest, most confident change.
- **Connector lazy refresh** — fixes the worker's cross-loop crash; fine for
  the long-lived API (refreshes on next connect near expiry).
- **CI repoints the job** — jobs were drifting onto hand-tagged stale images;
  now `race-postprocess` tracks the build image automatically.
- **Review screen**: finished races route to it; stats render immediately,
  AI Coach polls until the recap lands.
