### Phase 2 — c1 + c2: routing pipeline collapse

**Bug fixes that surfaced (silently wrong in prod before this):**
- Worker omitted `duration_hours` when calling `load_forecast_for_race` and `load_currents_for_race`. Different forecast horizons for the same race.

## Decisions made and rationale

- **Worker reads stored RouteRequest from Redis (not row JSONB).** 7d TTL, falls back to defaults on miss. Cheaper than an Alembic migration, Redis-flush-resilient (cold start uses defaults, same as today's worker did unconditionally). Logged when fallback fires so we can measure frequency.
- **Cache key stays deterministic string, not stable hash.** Debuggability beats key length for a low-write cache — `redis-cli KEYS route:*` triage still works.
- **`RouteRequest` is `@dataclass(frozen=True)`, not pydantic.** Pydantic stays at the wire (`ComputeRouteIn`). Decouples the domain type from FastAPI.
- **`ForecastNotAvailable` stays as raised exception** instead of a sum type. Both callers handle differently anyway (router → HTTP 425, worker → silent skip). Sum type would be churn for no gain.
- **Engine sync inside the event loop.** Punted asyncio.to_thread offload — separate concern from collapsing orchestration. Revisit if event-loop blocking proves real.
- **B+ over A for ingest.** Forced abstraction over four heterogeneous workers would carry "which hook do I implement" cognitive cost on every new worker. Bathy and ENC are genuinely one-shot static; weather, currents (and future wave, ECMWF, SST) are cycle-based. Right level of reuse: pipeline for cycle-based, `GcsArchive` for all four.
- **Manifest schema stays per-source** (returned by `SnapshotSource.build_manifest_fields`). Adding a manifest field is a one-file change.
- **N domain-buckets stays for now**, GcsArchive future-proofs consolidation. Per the handoff, consolidation has IAM implications and is a separate ticket.

- The currents dry-run no longer writes a topology blob to disk (the `persist_first_snapshot_extras` hook is gated to non-dry-run mode in the pipeline). Existing tests don't assert on this. If you want it back for dev inspection, the cleanest fix is a `dry_run_persist_extras(dry_run_dir, snapshot)` method on `SnapshotSource` — not worth doing until someone misses it.
- `compute_isochrone_route_multileg` is sync inside the async `compute_route`. Likely fine — race compute is human-tempo. `asyncio.to_thread` is the answer when/if event-loop blocking shows up under load.
- `_assert_race_owned` in `routing.py` does an inline import of `auth_helpers` (`from app.auth_helpers import race_write_predicate`). Pre-existing — kept as-is because it's a circular-import dodge.
