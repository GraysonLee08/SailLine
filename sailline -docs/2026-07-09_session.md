ran once, on-water or in sims. Fixed this session: his row set to
`pro` in Cloud SQL (verified via SELECT).

## Phase A — built this session

### Files changed

- `backend/app/services/redis_keys.py` — `TACTICS_TRACE_TTL_S` (24 h),
  `tactics_trace_key` → `tactics:trace:{race_id}`.
- `backend/app/services/tactics/trace.py` — **new.** `EvalTrace`
  accumulator; one compact JSON record per evaluation to a Redis ring
  buffer (LPUSH + LTRIM 200 + EXPIRE); never raises; 13 pinned exit
  reasons.
- `backend/app/services/tactics/pipeline.py` — every exit traced
  (incl. cooldown-skipped runs, so "alive but quiet" ≠ "never
  spawned"); one structured log line per evaluation (Cloud Logging is
  the durable copy); `_evaluate` split into gate + `_evaluate_inner`
  with an `error` trace on exception. **Behavior change:** transient
  exits (`insufficient_track`, `no_forecast`) now RELEASE the global
  cooldown they acquired; permanent gates keep it.
- `backend/app/routers/tactics_debug.py` — **new.**
  `GET /api/races/{id}/tactics/debug` → traces + latest call + live
  cooldown TTLs. Read-predicate auth, 404-no-leak, 503 when Redis down.
- `backend/app/main.py` — router mounted.
- `backend/tests/test_redis_keys.py` — trace key + TTL fingerprints.
- `backend/tests/test_tactics_trace.py` — **new**, 12 tests: trace
  shape/ring/never-raises/unknown-reason, pinned exit-reason set,
  pipeline exits with mocked pool+redis (cooldown_global, opted_out
  keeps cooldown, no_forecast releases it, error), debug endpoint
  (404 / happy path / 503). Starts paying down the "pipeline has no
  mocked-I/O test" debt from 2026-06-11.

No migration. No mobile changes. Deploy = normal push.

### Decisions + rationale

- Trace even cooldown-skipped evaluations — an empty buffer then
  cleanly means "task never spawned" (the exact failure we just spent
  a month not seeing).
- Cooldown release on transient exits only — permanent gates keep the
  SETNX so opted-out/ended races re-check once per 180 s, not per batch.
- Near-miss numbers come from the eval context (pinching/off-pace/heel
  readable in every trace); maneuver-detector internals (layline ETA
  when not firing) deferred to the Phase B harness rather than
  rewriting 7 detectors.
- Advisor SILENT vs failure not distinguished in the trace yet — needs
  a reason threaded through `generate_call`; Phase B if it matters.
